## Getting Started

### Prerequisites

- Node.js 18+ (tested on Node.js 24)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/pyandraanugrah/developer-log.git

# Navigate to project directory
cd developer-log

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

### Build & Production

```bash
# Typecheck
npm run typecheck

# Lint
npm run lint

# Production build
npm run build
```
